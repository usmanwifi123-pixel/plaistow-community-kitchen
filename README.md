# Plaistow Community Kitchen

## Project Overview

This is a work experience project focused on designing a simple prototype to help Plaistow Community Kitchen organise volunteer shifts, rota information and stock records.

## The Problem

Managing volunteer bookings and stock manually can be time-consuming. The proposed system aims to make information easier to find and reduce the risk of double-booked shifts.

## Prototype Features

- **Coordinator Dashboard:** Overview of volunteer and stock information.
- **Volunteers:** Displays example volunteer records.
- **Shift Bookings:** Shows how shift booking information could be organised.
- **Tonight's Rota:** Displays an example rota.
- **Stock Management:** Organises example stock information.

## Design and Testing

The prototype was designed in Figma with consistent navigation and readability in mind. Initial checks covered navigation, layout and a phone-sized view. Two people provided feedback that the navigation was easy to understand.

## Limitations

This is a clickable design prototype, not a complete working application. It does not use a live database or automatically prevent double bookings. Further development and testing would be needed.

## Future Improvements

- Add a database and secure user accounts.
- Prevent double-booking of shifts.
- Add low-stock warnings.
- Conduct further usability testing.

## Project Status

The design prototype and supporting documentation were prepared as part of a work experience project.
